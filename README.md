# Webora Tec Internship - Task 1

## Project Overview
This is a simple backend API built with Node.js and Express for the Webora Tec Internship (Task 1). It returns a welcome message and an about description in JSON format.

## Tools Used
- Node.js
- Express.js

## How to Run
1. Install dependencies:
   `npm install`
2. Start the server:
   `node server.js`
3. Open your browser and go to:
   `http://localhost:3000` (Welcome route)
   `http://localhost:3000/about` (About route)
